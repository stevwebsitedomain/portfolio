# Yii3 (yiisoft/app) — advanced-style layout

Yii3 haina template rasmi inayoitwa "advanced" kama Yii2. Hii repo inatumia **Yii3 official web template** na kuipanga kama advanced:

- `src/Web/` — frontend (kurasa za tovuti)
- `src/Backend/` — backend API
- `src/Shared/` — common
- `src/Console/` — console
- `public/` — web root (XAMPP)

```bash
copy .env.example .env
composer install --ignore-platform-reqs
php yii serve --docroot=public --port=8080
```
